# CACIS vNext owner brief

Source: owner-supplied architecture direction, normalized 2026-07-15  
Status: source input, not doctrine and not implementation evidence

## Vision

Transform nimrod from constitutional orchestration into a Constitutional Autonomous Cyber Immune System (CACIS): a living defensive intelligence that models digital reality, creates competing threat hypotheses, challenges its own conclusions, independently verifies containment and recovery, learns through evidence-gated replay, and permanently preserves human authority.

## Immutable laws

1. Truth before action: evidence, provenance, independent verification, and causal replay outrank agent or tool claims.
2. Authority never evolves: execution rights, trust roots, constitutional law, recovery gates, operator authority, and safety ceilings cannot be widened by learning.
3. Security is a living world: observation, understanding, hypothesis, challenge, verification, recovery, and learning replace an alert-to-ticket pipeline.
4. Every decision survives skepticism: counter-evidence, uncertainty, replay, and recovery validation remain first-class.
5. Every failure creates knowledge: incidents become lessons, patterns, theories, genomes, and safer future organisms.

## Target capabilities

- A constitutional kernel containing authority, permission, evidence, truth, execution, recovery, promotion, evolution, and replay law.
- A sovereign governor that spawns and terminates temporary immune organisms, schedules investigations, and allocates resources but never authorizes execution.
- A continuously updated probabilistic world model for identity, endpoint, network, cloud, threat, and recovery state.
- Temporary incident-specific organisms assembled from perception, modeling, hypothesis, challenge, verification, containment, recovery, evidence, historian, and shadow roles. The organism ends; its governed knowledge survives.
- Typed evidence protocols for observations, measurements, hypotheses, counter-evidence, unknowns, abstentions, proposals, verification, settlement, mutation, and health. Unrestricted agent chat never carries authority.
- Competing hypotheses, adversarial challengers, independent verifiers, and a shadow controller that can pause or terminate but never authorize.
- A metacognitive cortex that separates model, evidence, telemetry, historical, calibration, verification, and recovery confidence.
- Metabolism, homeostasis, and Chronos controls for information gain, risk reduction, resource pressure, sensor health, backlog, and multiple operational time scales.
- Layered memory and a genome of investigation, containment, recovery, verification, threat-model, and organism patterns.
- A Constitutional Evolution Foundry that may improve hypotheses, investigations, recovery, verification, organizations, prioritization, simulation, and threat models, but never authority, execution, trust, or constitution.
- Visible, private, and external evaluation partitions; reward-hacking defenses; complexity gates; security arenas; and an evidence-first Observatory.
- Recursive improvement levels 0 through 5, ending at improving the improver without any right to modify constitutional authority.

## Offense and defense boundary

Authorized offensive testing is required to validate defense. It remains subordinate to existing Crucible gates: owner-controlled offline replicas, isolated ranges, exact target graphs, signed authorization leases, effect ceilings, independent abort, cleanup, recovery, and verification. Public hosts and third-party deployments are never targets merely because their source is public.

## Architectural instruction

Treat the named repository areas as logical capability boundaries and an end-state map, not an instruction to create empty packages or parallel implementations. Reuse existing nimrod authority, evidence, verifier, swarm, Crucible, Foundry, and control-board boundaries wherever they already satisfy the intent.
