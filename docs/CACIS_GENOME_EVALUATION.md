# CACIS W5 genome evaluation

W5 turns governed replay lessons into one immutable candidate-only genome. Its lineage binds the credential-theft lifecycle, suspicious-script lifecycle, separately verified CIRE settlement, and W4 homeostasis receipt.

Memory is stratified across observation, incident, investigation, containment, recovery, failure, theory, genome, and civilization. Raw evidence is not retained in genome strata. The candidate is evaluated across visible, sealed private, and sealed external replay partitions; the labels describe partition roles, not real external replication.

All nine reward-hacking defenses are explicit: future leakage, telemetry leakage, replay contamination, simulation exploitation, verifier exploitation, authority expansion, confidence gaming, recovery gaming, and complexity inflation. Seven complexity metrics gate state size, dependencies, replay cost, runtime, maintainability, explanation complexity, and dead code. Distillation must reduce state while preserving replay semantics.

Passing W5 produces only a content-addressed candidate. It cannot promote, generalize, authorize, execute, contact targets, modify trust, or modify the constitution. Real sealed evaluators and forward/external replication remain blocked.
