## [Unreleased]

### Added
- Autonomous two-role Tier A/B shadow promotion with four-evaluator assurance, exactly-once publication, crash recovery, and automatic regression demotion.
- Wheel-content integration validation covering all six source packages and fourteen advertised command modules.
- Live read-only identity and effective-ACL readiness probes for the World Model, CIRE, and Observatory verifier surfaces, preserving dedicated-account, egress, administration, and custody blockers.
- Exact 97-contract static conformance matrix separating schema, semantic, runtime-reference, and independent-harness evidence while denying live or production conformance claims.
- Coverage measurement job (`coverage`) that replays the `validate_*.py` contract ladder under coverage.py, reporting `src` package line coverage in the CI job summary with a `--fail-under` floor.
- `CHANGELOG.md` following the Keep a Changelog format.
- Suspicious-script immune-organism morphology and bounded continuous Windows PowerShell, Sysmon, and DNS defensive observation.
- Separate-process constitutional intelligence verification with input-integrity and credential-environment isolation checks.
- W5 candidate-only genome evaluation with sealed replay partitions, reward-hacking defenses, complexity gates, and distillation evidence.
- W6 multidimensional replay arenas and a threshold-signed, freshness-bound, display-only Observatory projection.
- Replay-safe continuous-observation World Model succession with durable source cursors, explicit gap and sensor-health evidence, and separate-process causal verification.
- Threshold-signed replay source governance with purpose and retention binding, bounded queue backpressure, freshness and clock-skew evidence, actual-store projection checks, and separate-process verification.

### Changed
- Distribution discovery now includes `nimrod_research`, so the `nimrod-intelligence-research-replay` command is functional outside an editable checkout.
- Distribution validation builds from an isolated temporary source copy, and canonical manifests exclude ignored build output.
- Windows authorization-state publication retries only transient `WinError 5` races within a fixed bound and raises explicitly after exhaustion.
- The control board and CACIS roadmap now expose evidence-backed W1-W6 status while retaining the W7 live-range gate.
- W1 immutable storage now supports predecessor-bound successor generations and fail-closed recovery of the world-ahead/cursor-prepared publication window.
